# Appendix I: Internationalization Support

*This appendix is informative, not normative.*

## <a id="Intro"></a>I.1 Introduction

This appendix provides a brief summary of SVG's support for internationalization. The appendix is hyperlinked to the sections of the specification which elaborate on particular topics.

## <a id="InternationalizationAndSVG"></a>I.2 Internationalization and SVG

SVG is an application of XML [[XML10](refs.md#ref-XML10)] and thus supports Unicode [[UNICODE](refs.md#ref-UNICODE)], which defines a standard universal character set.

Additionally, SVG provides a mechanism for precise control of the glyphs used to draw text strings, which is described in [Alternate glyphs](text.md#AlternateGlyphs). This facility provides:

- the ability to specify the rendering of particular glyphs which might not be accessible when defining character data using Unicode
- the ability to override the user agent's character-to-glyph algorithms
- the ability to follow the guidelines for normalizing character data for the purposes of enhanced interoperability (see Character Model for the World Wide Web 1.0: Fundamentals [[CHARMOD](refs.md#ref-CHARMOD)]), while still having precise control over the glyphs that are drawn.

SVG supports:

- Horizontal, left-to-right text found in Roman scripts (see the [‘writing-mode’](text.md#WritingModeProperty) property)
- Vertical and vertical-ideographic text (see the [‘writing-mode’](text.md#WritingModeProperty) property)
- Bidirectional text (for languages such as Arabic and Hebrew - see the [‘direction’](text.md#DirectionProperty) and [‘unicode-bidi’](text.md#UnicodeBidiProperty) properties)

[SVG fonts](fonts.md#SVGFonts) support contextual glyph selection for [Arabic](fonts.md#GlyphElementArabicFormAttribute) and [Han](fonts.md#GlyphElementLangAttribute) text.

<a id="I18nTextSubstitution"></a>Multi-language SVG documents are possible by utilizing the [‘systemLanguage’](struct.md#SystemLanguageAttribute) attribute to have different text strings appear based on the client machine's language setting.

## <a id="SVGInternationalizationGuidelines"></a>I.3 SVG Internationalization Guidelines

SVG generators should follow W3C guidelines for normalizing character data [[CHARMOD](refs.md#ref-CHARMOD)]. When precise control over glyph selection is required, use the facilities for [Alternate glyphs](text.md#AlternateGlyphs) to override the user agent's character-to-glyph mapping algorithms.
